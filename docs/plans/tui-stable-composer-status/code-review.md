## 已修复问题

1. **P1：短屏确认正文不可完整阅读。** wrapToRows 原先按 UTF-16 长度预换行，中文及 emoji 实际占列超过预算后被 Text truncate 截掉，翻页无法找回。共享换行器改用已有字素分段及显示列测量；40/80 列真实 Ink 回归逐页重组完整正文。修复前 5 项失败，修复后相关 60 项通过。
2. **P2：详情残留已失效的退出／停止提示。** 手势状态 1500ms 到期，重复 toast 仍存活 2500ms，导致详情提示与下一次按键含义不符。移除手势状态的重复 toast，以现有事实投影和显式刷新驱动反馈，同时清理卸载计时器。修复前 2 项失败；修复后状态、反馈、中断梯级与 App 四文件 100 项通过。
3. 清理 App 中关于输入随文档滚动、延迟缩小和旧更新行的过时注释，避免误导后续维护。
